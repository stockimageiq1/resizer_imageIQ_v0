# Installing ImageIQ Resizer

ImageIQ Resizer is available for **Mac**. It is signed with our Apple Developer
ID and notarized by Apple. Windows comes later.

## macOS (.dmg)

1. Download the version for your Mac:
   - Apple silicon (M1 and newer): `ImageIQ-Resizer-mac-arm64.dmg`
   - Intel: `ImageIQ-Resizer-mac-x64.dmg`
2. Open the `.dmg` and drag **ImageIQ Resizer** into **Applications**.
3. Open the app from Applications. The first time, macOS asks:

   > “ImageIQ Resizer” is an app downloaded from the Internet. Are you sure you
   > want to open it? Apple checked it for malicious software and none was
   > detected.

   Click **Open**. That is the only security warning you should see (macOS
   may also ask once for access to a folder; that is normal). If macOS says it
   cannot verify the app, do not bypass the warning: download it again from
   the link we sent you and tell us.

Already using an older, unsigned version (0.3.x)? It cannot update itself.
Install this one the same way and choose **Replace** when asked.

## Updates

The app checks for a new version when it starts and offers **Download &
Restart**. If a resize is running, it finishes first. Updates install only when
the app is in **Applications**, not when it runs from the `.dmg`. If you are
offline, nothing happens and nothing is shown.
